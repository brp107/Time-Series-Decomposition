# Time-Series-Decomposition

This folder decomposes the US Candy Production Index into its trend, seasonal, and irregular components in R.

This analysis uses an updated version of the dataset, `candy.csv`, in place of the original Kaggle file.

Source | FRED series [IPG3113N](https://fred.stlouisfed.org/series/IPG3113N)

Time span | Jan 1972 to Aug 2026

Observations | 656
